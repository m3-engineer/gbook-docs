- **SSD safety:** `BLK_DEV_NVME` is `=m` and guarded by `# forbid-y:` in the fragment, so enumeration read config

- **Deferred now:** only `arm-scmi` ("failed to setup channels"). PCIe, USB, the GPU SMMU, the DP aux bridges and
  `pmic-glink` all probed.

## What made it work

The QMP PCIe PHY was `=m`. The Wi-Fi port also needs `PCI_PWRCTRL_PWRSEQ`, which has no prompt and is selected only
by `ATH11K`/`ATH12K`; `ATH12K` in turn needs `MAC80211`, `CFG80211` and `RFKILL` built in
(`scripts/dt-kconfig-map.py`, `scripts/build-kernel.sh` demotion check).
