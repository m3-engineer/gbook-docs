## What worked

- `/init` found ROOT by `kern_guid` (`root-lookup`: the booted disk's partition 2 is `gbook-root`), mounted it
  (`init=/sbin/init`), sent its netlog, and `exec switch_root`ed (`GBOOK: switch_root=/dev/sda2`), both boots.
- systemd 262.1 booted Debian sid arm64 from the stick; the journal is persistent on ROOT.
- **Mesa on the GPU** (M3 criterion): `eglinfo -B`: OpenGL 4.6 Core and Compatibility, vendor freedreno, renderer
  "Adreno X1-85", Mesa 26.2.6-1; `kmscube -D /dev/dri/card2 -c 120`: exit 0, OpenGL ES 3.2, renderer "Adreno X1-85";
  cage (`-d`): "EGL driver name: msm", "GL renderer: Adreno X1-85", GLES2 renderer on `eDP-1` at 2560x1600, 120 Hz.
  `/dev/dri/by-path`: `platform-3d00000.gpu-card -> card1`, `-render -> renderD128`,
  `platform-ae01000.display-controller-card -> card2` (`msm.separate_gpu_kms=1`).
- **Ghostty 1.4.0+gbook** (the cross build) ran under cage as user `gbook` with a bash shell; the owner typed in it
  (`which ghostty` gave `/usr/local/bin/ghostty`). Boot 1's `m3-cage=inactive` was an ordering bug (`After=gbook-m3`
  held the unit until the capture script ended); boot 2 captured it active with the renderer line.
- **Wi-Fi in userspace** (M3 criterion), boot 2: with `10-wlan0.link` the interface kept its name; `wpa_supplicant@wlan0`
  (reading `/run/gbook/wpa_supplicant.conf`) joined: `Connected`, 6135 MHz, -38 dBm, rx 1297 / tx 3843 Mbit/s 320 MHz
  EHT; networkd: "State: routable (configured)", "Online state: online", a DHCPv4 address via <the gateway>.
- **Audio state known** (M3 criterion): `aplay -l`: "no soundcards found" (no sound node in the DTS; ticket 10).
- Both boots powered down cleanly on the owner's command (`reboot: Power down`, EC `G3`).
